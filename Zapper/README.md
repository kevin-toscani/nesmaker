# Zapper

Zapper is a NESMaker 4.5.x script that adds zapper support to your NESMaker game.

## Implementation & Usage

You can follow the guide provided on [the forum](https://nesmakers.com/index.php?threads/4-5-9-adding-zapper-support.8362/) or on [my blog](https://nesmaker.nerdboard.nl/2023/11/24/faq-can-nesmaker-do-zapper-games/).
